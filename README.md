# personal-claude-lab

Personal workspace for exploring and deploying AI projects powered by the Claude API.

## Projects

| Project | Description | Status |
|---|---|---|
| [Debt Tracker](projects/debt-tracker/) | Split a restaurant bill from a receipt photo — per-person invite links, payment tracking | Built (local) |
| [Financial Analysis Tools](projects/financial-analysis/) | Investment analysis tools — earnings reports, SEC filings, portfolio commentary | Planned |
| [News Summarizer & Learning Materials](projects/news-summarizer/) | Daily news digest and learning content (flashcards, Q&A) generated by Claude | Planned |
| [Reader Assistant](projects/reader-assistant/) | Reading companion — EN↔中文 translation, notes/quotes, book chat, summary + rating | Built (local) |
| [Hangout Organizer](projects/hangout-organizer/) | Weekly badminton/pickleball polls with booking quorum, venue directory, event checklists | Built (deployable) |

## Repo Structure

```
personal-claude-lab/
├── projects/
│   ├── debt-tracker/          # Bill splitting from a receipt photo
│   ├── financial-analysis/    # Financial analysis tools
│   ├── news-summarizer/       # Daily news summarizer
│   ├── reader-assistant/      # Reading companion
│   └── hangout-organizer/     # Group scheduling + event checklists (deployed)
├── shared/                    # Shared Claude API client and utilities
├── .env.example               # API key template
└── README.md
```

## Setup

1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your API keys
3. Navigate to the relevant project under `projects/` and follow its README

## Requirements

- [Claude API key](https://console.anthropic.com/) — note this is billed separately from a
  claude.ai Pro subscription. `hangout-organizer` needs no AI key at all.
- Python 3.11+ or Node.js 20+ (per project)

## A note on env files

Most projects read the root `.env`. `hangout-organizer` is the exception: it deploys to Vercel and
carries its own `projects/hangout-organizer/.env.local`.
