Two setup traps, both hit for real:

1. Create the host auth user BEFORE disabling public signups.
   signInWithOtp defaults to shouldCreateUser:true, so on a fresh project with signups off you
   get "Signups not allowed for this instance" and there is no way in — nobody can sign in
   because nobody exists, and nobody can be created. Fixed by creating the user through the
   admin API (Authentication -> Users -> Add user does the same thing).

2. Do not paste real keys into .env.local.example — that file is TRACKED. They belong in
   .env.local, which is gitignored. This happened and was cleaned out of git history before
   anything was pushed.
