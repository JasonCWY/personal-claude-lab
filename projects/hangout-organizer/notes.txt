THE BIG CHANGE THIS SESSION: restructured around POLLS.

A poll owns the window + share token. Sessions hang off it as the things being booked, each with
its own quorum rule. Availability belongs to the POLL, not the session — because whether someone
is free on Tuesday has nothing to do with which sport is planned. Consequences:
  - Badminton and pickleball over the same dates = ONE link, ONE grid, both scored.
  - Adding an activity to a running poll needs nobody to re-answer.
  - Clash detection is possible at all: overlappingPeople() warns when two confirmed sessions
    overlap in time with the same people in both.

Also added:
  - Roster GROUPS. Poll addressed to everyone / a group / hand-picked people. The resolved list is
    FROZEN onto the poll (poll_invitees) — editing a group later never changes who a running poll
    went to. Public page lists only invitees; the write endpoint rejects anyone else.
  - groupCandidates() collapses overlapping bookable windows. A 3-hour free stretch was showing as
    five near-identical rows; now one block with the start times inside it, drawn as bars on a
    per-day timeline. Merging stops where the sustained headcount would drop.
  - Editable WhatsApp message preview before copying.
  - Grid: month in the day header (repeated only where it changes), row labels are slot RANGES
    (19:00–19:30) not bare starts, 15-minute slots allowed.
  - Overnight windows: day_end_time <= day_start_time means the next day. 22:00–00:00 works.

TWO GOTCHAS WORTH REMEMBERING:
1. Create the host auth user BEFORE disabling public signups. signInWithOtp defaults to
   shouldCreateUser:true, so on a fresh project with signups off nobody can ever get in.
2. Never paste real keys into .env.local.example — that file is TRACKED. They go in .env.local.
   Also: adding a new secret key does NOT revoke the legacy service_role JWT; disable legacy keys
   explicitly under Settings → API Keys.

Dev server gotcha: stopping the npm task leaves the node child holding port 3000, so a restart
silently lands on 3001 and you end up testing the OLD build. Kill the PID on the port. Also, after
editing several shared modules, the dev bundler can corrupt — delete .next and restart.
